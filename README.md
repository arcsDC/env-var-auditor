# env-var-auditor

A CLI tool that audits .env files for missing, unused, and duplicate variables against a schema.

## Stack

Primary language: **TypeScript**

## Project structure

- `src/index.ts` — Validate environment variable configurations against a defined schema.
- `package.json` — dependencies
- `tests/test_main.ts` — basic tests

## Usage

Review the source files and install any dependencies referenced by the project before running it.
